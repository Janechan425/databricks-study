## 使用规则

1. 阅读教材时用 Obsidian 批注，不复制整章内容。
2. 有价值的解释导出为 Markdown，归档到 `my-notes/`。
3. 保留来源链接、简短解释与实际例子，优先整理容易混淆的知识点。
4. 不将公司代码、内部数据或机密资料提交到个人仓库。

> 注意：Obsidian 插件的批注可能保存在 `.obsidian/plugins/` 配置中，未必自动进入 GitHub；建议使用插件的 Markdown 导出功能保存为普通 `.md` 文件。
